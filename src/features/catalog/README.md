# Catalog

contracts.ts определяет публичный DTO и фильтры. service.ts содержит только
синтетический набор demo-catalog-v1 и детерминированный поиск: обязательный язык
исключает unknown, известный возраст исключает несовместимые диапазоны,
неизвестный возраст разрешается явным флагом. catalog-screen.tsx — UI списка,
фильтров и нативного dialog с выбором цели. БД и реальные контакты не используются.
