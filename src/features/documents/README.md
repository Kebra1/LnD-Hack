# Documents

service.ts содержит три явно синтетических текстовых примера и подготовленные
факты mode=fixture. Цитата должна буквально присутствовать на исходной странице.
Pending/rejected не создают целей; corrected хранит origin=user_correction при
неизменной цитате. Срок включителен в Asia/Almaty, просроченный остаётся историческим.
Последний review хранится в памяти вкладки в demo-shell.

Это демонстрация review, не PDF parsing и не live AI. Провайдер/ключ не настроены.
PDF.js, allowlist/hash и server-side AI adapter из главы 7 архитектуры остаются
следующим этапом. Реальные файлы этот интерфейс не принимает.
