# Routes

service.ts содержит чистый reducer целей и выбранных вариантов. Повторные id
не создают дубликаты, добавление варианта сохраняет выполнение цели. В demo-shell
состояние принадлежит общему locale layout конкретной вкладки: refresh очищает
его, переходы Next Link сохраняют. Хранилища браузера и PostgreSQL не используются.
